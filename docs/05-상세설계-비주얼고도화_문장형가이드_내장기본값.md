# 모비노기 AI도우미 (MobiMate) — 비주얼 디자인 전면 고도화, 문장형 가이드 쉘프 및 내장 가이드 기본값 상세설계서 (v5)

## 1. 개요 및 설계 목적

### 1.1 사용자 피드백 요약
1. **불필요한 팁 문구 제거 및 툴팁 이관**:
   - 대화창을 어지럽히던 `💡 팁: 더 자유롭고 심층적인 자연어 AI 대화를 원하시면...` 텍스트를 응답 본문에서 완전히 제거.
   - 해당 내용은 `엔진:` 라벨의 툴팁 및 상단 캡슐형 슬림 안내 배너로 이관.
2. **가이드다운 '문장형 공략 가이드 쉘프' 구축**:
   - 5개의 작은 단축 버튼을 대체하여, 사용자가 읽고 고를 수 있는 **완성형 질문 문장 카드(Guide Shelf)**를 제공.
   - 문장 카드를 클릭하면 대화창에 사용자 질문 말풍선이 자연스럽게 들어가고, 정갈한 공략 답변이 챗창에 출력되어 진짜 대화형 가이드의 경험을 제공.
3. **내장 마비 가이드의 상시 기본값(Default) 고정**:
   - PC에 Ollama나 CLI가 설치되어 있더라도, **무조건 `[무료/내장] 💡 내장 마비 가이드`가 최초 기본값**으로 자동 선택되도록 변경.
   - 무료/안정적인 0원 공략을 기본으로 보고, 원할 때 Ollama나 CLI로 전환하도록 지원.
4. **전체 UI 디자인 비주얼 고도화 (Modern Gaming Dark UI)**:
   - 디스코드/스팀 오버레이 수준의 프리미엄 게이밍 다크 테마 적용.
   - 깊이감 있는 다크 배경(#0F1012 / #181A1E), 세련된 1px 글래스 보더(#2D3139), 소프트 액센트 그라데이션, 말풍선 타이포그래피 정돈.

## 2. 세부 설계 사양

### 2.1 내장 마비 가이드 기본값 정책 (`AiEngineManager`)
- `AiEngineManager.DiscoverEnginesAsync()`:
  - 기존: Ollama 모델이 있으면 1순위로 Ollama 자동 선택.
  - **개정**: 감지된 엔진 목록에 상관없이 **`_currentEngine = builtInGuide;`를 최초 기본값으로 강제 지정**.
  - 사용자가 이전 세션에서 명시적으로 변경한 이력이 없는 한, 앱 기동 시 항상 안전하고 100% 무료인 내장 가이드가 기본 선택됨.

### 2.2 문장형 공략 가이드 쉘프 (Guide Shelf)
- **배치 위치**: AI 대화창 입력부 상단 (내장 가이드 모드 시 노출, 가로 스크롤).
- **제공되는 6대 완성형 문장 카드**:
  1. ⚔️ **"현재 전투력 기준 1티어 룬 세팅 및 무기 각인 공략"**
  2. 💰 **"일일 미션과 요일 던전 보상으로 골드 빠르게 모으기"**
  3. 🌿 **"가공 시설 쿨타임 관리법과 철광석·약초·목재 채집 명당"**
  4. 🛡️ **"보스 브레이크 게이지 파훼법 및 장판 회피 요령"**
  5. 📊 **"현재 캐릭터 실시간 스탯, 전투력, 가방, 미션 정밀 진단"**
  6. 🎒 **"가방 무게 초과 방지 및 계정 창고/캐릭터 창고 정리법"**
- **동작 방식**:
  - 카드 클릭 시 `ExecuteAiQueryDirect(cardText)` 실행.
  - 챗창에 `나: [해당 질문 문장]` 말풍선 생성 후, 내장 가이드의 핵심 공략이 말풍선으로 깔끔하게 응답.

### 2.3 대화창 다이어트 및 툴팁/상시 배너 안내
- **`BuiltInGuideEngine.cs`**:
  - 하단 고정 팁 문구 전면 제거. 순수 공략과 캐릭터 진단 데이터만 반환.
- **`엔진:` 툴팁**:
  - `ToolTip="현재 응답 엔진입니다. Ollama(로컬 LLM) 또는 CLI 에이전트가 설치되어 있으면 드롭다운에서 전환하여 더 자유롭고 풍부한 자연어 대화를 나눌 수 있습니다."`
- **상시 슬림 안내 배너**:
  - 헤더와 피드 사이에 1줄 캡슐형 미니 배너 배치:
    `"💡 무료 내장 가이드 모드 | 🤖 PC에 Ollama·CLI 설치 시 드롭다운에서 자유 대화 가능"`

### 2.4 모던 게이밍 다크 테마 비주얼 리디자인
- **색상 체계**:
  - 메인 배경: `#0F1012` (깊은 매트 블랙)
  - 서브/컨테이너 배경: `#181A1E`
  - 카드/패널 배경: `#22252B`
  - 인풋/아이템 배경: `#1A1C21`
  - 주 액센트: 인디고 블루 `#5865F2` (부드러운 하이라이트)
  - 보조 액센트: 골드 `#FFA000`, 사이언 `#00BCD4`, 에메랄드 `#23A55A`
  - 보더: `#2E323B` (은은한 1px 라인)
- **카드 및 탭 스타일**:
  - 탭 버튼: 선택 시 하단 또는 상단 3px 네온 액센트 바, 둥근 코너(8px).
  - 대화 말풍선:
    - 사용자: `#2E3856` (부드러운 딥 인디고)
    - AI/가이드: `#1E222B` (차분한 다크 슬레이트), 좌측 2px 액센트 블루 라인 포인트.
  - 가이드 쉘프 카드:
    - 가로 방향으로 나열되는 컴팩트 카드 형태 (`CornerRadius=8`, 패딩 8px, 호버 시 배경 `#2D323E` 발광).
