# 임무 탭 설계 (2026-10-24)

## 탭 구성

- **가방 탭**: 다이어트 보기만 둔다(가방 무게 게이지, 위치 구분, 다이어트 대상 별, 정렬). 임무용 아이템은 여기에서 뺐다.
- **임무 탭**(새로 만듦, 주소 `/mission`, 단축키 9, 폰 하단 탭에도 추가): 맨 위에서 세 모드를 고른다.
  - **채집**: 채집 임무용 20종을 마을 순으로, 가진 개수가 0이어도 모두 보여 준다(0개는 흐리게). 검색·정렬 가능.
  - **요리**: 제작과 같은 계산기. 완성품 개수를 알 수 있어 이미 가진 요리는 목표에서 빼고 계산한다. 레시피는 `MISSION_CRAFT_RECIPES.md`.
  - **제작**: 아래 계산기.

## 제작 계산기

목적 두 가지: (1) 지금 재료로 각 제작품을 몇 개 만들 수 있나, (2) 퀘스트 목표 개수를 만들려면 재료가 얼마나 더 필요한가.

```
[채집][요리][제작]
제작 계산 · 레시피 14종
[창고 재료 포함] [목표 모두 지우기]
┌ 마을별 레시피 카드(폭 232px 고정) ────────────┐ ┌ 필요한 재료 ──────────┐
│ 이름                 ×5 · 3회   [재료 부족]    │ │ 제작 8회 · 모자란 재료 7종│
│ 지금 N개 가능              목표 [− 3 +]        │ │ 재료  필요  보유  부족   │
│ 재료A 2  재료B 2  (부족한 재료는 빨강)          │ │ 강철괴  10    0   10    │
└────────────────────────────────────────────────┘ │ ...                    │
                                                   └────────────────────────┘
```

- 카드 3줄: ①이름(+1회 생산량·제작 횟수, 목표가 있으면 "재료 충분/부족" 표시) ②"지금 N개 가능"과 목표 입력 ③재료 칩.
- 넓은 화면(900px 이상): 카드 격자 + 오른쪽 요약 패널(스크롤해도 따라옴). 좁으면 요약 패널이 카드 아래로 내려간다.
- 목표는 카드 안 숫자 칸(− 입력 +)으로 넣고, 이 기기 브라우저에 저장해 둔다(`mobimate.craftTargets`).

### 계산 규칙 (`lib/craft.ts`)

- **가진 개수** = 가방 + 계정 창고 + 캐릭터 창고 (옵션으로 가방만). 창고 재료는 이동 비용(분해된 장비 부품)을 내면 제작에 쓸 수 있다.
- **지금 몇 개 가능**: 레시피별로 단독 계산 — `min(가진 재료 ÷ 1회 필요량)` 횟수 × 1회 생산량. 다른 레시피와 재료를 나누지 않는다.
- **목표 계획**: 목표 개수를 1회 생산량으로 올림해 제작 횟수를 구하고, 모든 목표의 재료를 **합쳐서** 센다(같은 재료를 쓰는 레시피끼리 재료를 나눠 써야 하므로). 가진 것과 비교해 부족분을 계산하고, 부족한 재료를 쓰는 레시피에 "재료 부족"을 붙인다.
- 장비류 완성품은 게임이 개수를 알려 주지 않아(`get_items`에 장비가 없다) 세지 않는다. 재료만 센다.

### 데이터

- 레시피·임무용 아이템: `features/missionData.ts` (`RECIPES`, 채집·요리 표). 레시피 근거는 `MISSION_CRAFT_RECIPES.md`.
- 가진 개수: 기존 `/api/inventory`(get_items)를 그대로 쓴다. 서버 변경 없음.
