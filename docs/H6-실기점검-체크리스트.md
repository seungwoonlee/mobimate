# H6 실기 점검 체크리스트

承雲이 실제 게임으로 확인할 항목입니다. 결과 칸에는 O / X / 메모를 적습니다.

## 시작 전 준비

1. 웹앱이 **공유 저장 패치판(1.0.1011.1510 이후)** 인지 확인합니다(웹앱 제목줄·로그의 버전).
2. **기록을 수동으로 백업**합니다. `%APPDATA%\MobiMateWeb` 폴더를 통째로 복사해 두기를 권합니다(예: `%APPDATA%\MobiMateWeb-backup\날짜`). 저장할 때마다 `%APPDATA%\MobiMateWeb\*.bak`이 자동으로 남지만 한 세대뿐입니다.
3. .NET 8 데스크톱 런타임이 설치돼 있는지 확인합니다. `hw\dist\MobiMateHomeWork.exe`를 실행합니다.
4. 문제가 생기면 로그를 봅니다: `%APPDATA%\MobiMateWeb\logs\homework-*.log`.

## 점검 항목

| 번호 | 확인할 것 | 기대 결과 | 결과 |
|---|---|---|---|
| 1 | 첫 실행 위치 | 화면 4분할 위치에 뜬다(작업 표시줄에 가리지 않음) | |
| 2 | 다시 켰을 때 위치 복원 | 옮기고 크기를 바꾼 뒤 종료 → 다시 실행하면 같은 위치·크기 | |
| 3 | 캐릭터 전환 | 게임에서 캐릭터를 바꾸면 몇 초 안에 카드·선택 줄이 새 캐릭터로 바뀐다 | |
| 4 | 캐릭터 선택창 | 선택창에 있는 동안 엉뚱한 캐릭터에 기록이 섞이지 않는다 | |
