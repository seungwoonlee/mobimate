# 임무용 제작품 재료 조사 (2026-10-24)

임무용 보기에서 제작 카테고리를 뺀 뒤, 제작품을 만드는 데 필요한 재료를 조사한 기록이다.
게임 CLI `get_craftable_items`(레시피 이름으로 조회)의 응답을 그대로 옮겼다.

## 한계 (중요)

- `get_craftable_items`는 **부족한 재료만** `MissingIngredients`에 준다. 이미 충분히 가진 재료는 나오지 않고, 만들 수 있는 상태(`Craftable: true`)면 재료가 아예 비어 온다.
  그래서 아래 표는 **완전한 레시피가 아니라 "그 시점에 모자랐던 재료"** 다.
- 웹검색(2회)으로는 마비노기 모바일 제작 레시피를 담은 페이지를 찾지 못했다(다른 게임 결과뿐).
- 완전한 레시피를 얻으려면 (1) 게임 안 제작 화면에서 직접 옮기거나, (2) 재료를 하나도 안 가진 상태에서 조회해야 한다.

| 마법 유탄 부품 | 티르코네일 | (없음, 1회에 5개 생산) | 제작 가능 |

| 사슬 갑옷 신발 | 콜헨 | 강철괴 2 | 제작 불가 |
| 두꺼운 가죽 갑옷 신발 | 콜헨 | (없음) | 제작 가능 |

모든 제작품의 1회 생산 개수는 1개다(마법 유탄 부품만 5개).

## 참고: 다른 등급 레시피 (같은 조회에서 함께 나온 것)

- 크레센트 엣지소드S: 합금강괴 3, 상급 가죽 3 부족 / SS: 특수강괴 4, 상급 가죽+ 4, 항마석 가루 60, 지배의 도안(무기) 2 등.
- 론 엣지소드SS: 제작 가능.

(S·SS 등은 임무용 목록의 아이템이 아니다. 같은 이름 계열이라 함께 나온 것을 적어 둔다.)
