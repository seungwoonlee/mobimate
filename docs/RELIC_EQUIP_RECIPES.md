# 잔영·해연 장비 레시피 (CLI 조회, 2026-11-22)

`get_craftable_items`(제작)와 `get_alterable_items`(가공)로 읽은 값이다. 가방 탭 "장비 재료" 묶음(`web/src/client/src/features/stockData.ts`)의 근거.

- 제작 레시피는 재료 전체가 나온다. 가공 레시피는 **모자란 재료만** 나오고, 가공 대기열이 가득 차면 재료가 비어 나온다(queue_full). 그래서 가공 트리 일부(최상급·특급 목재 등)는 아직 재료를 다 알지 못한다.
