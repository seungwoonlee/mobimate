# MobiMate Web 실기 점검 체크리스트

> 대상: 承雲 PC(게임 설치) + 보유 기기 4종(아이폰 12 · 아이패드 에어 4 · 갤럭시 탭 S10 울트라 · 갤럭시 트라이폴드)
> 근거: 요구사양서 TST-05b · TST-07, 상세설계 §9 M1~M10
> 결과는 각 항목의 "결과" 칸에 적어 주시면 됩니다(○ / × / 메모). × 항목은 설명과 함께 알려 주시면 고칩니다.

## 0. 준비 (약 5분)

1. `web\dist\MobiMateWeb.exe`를 실행합니다(.NET 8 데스크톱 런타임 필요). 브라우저가 열리고 개요 화면이 보이면 됩니다.
   - 이미 실행 중이면 트레이의 **MobiMate → 브라우저 열기**를 누릅니다.
2. 게임을 켜고 설정에서 **"MM AI 에이전트"**를 켭니다. 상단 바 왼쪽 점이 초록이면 연결된 것입니다.
3. 폰·태블릿과 PC가 **같은 와이파이**인지 확인합니다. Windows 네트워크 프로필이 **개인**이어야 합니다.

## 1. 게임 PC에서 (게임 필요)

| # | 항목 | 방법 | 기대 결과 | 결과 |
|---|---|---|---|---|
| M1 | 채집 중 긴급 정지 | 생활 → 채집 도우미에서 아무 재료 [채집] → 3초 뒤 상단 **긴급 정지**(또는 Esc) | 채집이 1초 안에 멈추고 "채집을 멈췄습니다" 알림 | |
| M2 | 채집 목표 수량 | 목표 3개로 채집 시작 | 3개(또는 부족분) 모은 뒤 멈춤. 알림의 `+N개`가 맞음 | |
| M3 | 채팅 50자 단위 | 게임 채팅에 이모지 포함 49·50·51자 문장을 보냄 (예: 😊를 섞어서) | 게임 안에서 잘리지 않고 그대로 보임. 잘리면 몇 자에서 잘리는지 메모 | |
| M9 | 레이드 증표 재화 | 레이드 클리어 **전·후**로 재화 화면에서 `원정의 증거 … 레이드` 이름과 수량 확인. 다른 캐릭터로 바꿔서도 확인 | 정확한 이름 / 클리어 후 수량 증가 / 캐릭터마다 다른지(계정 공통이면 메모) | |
| — | 숙제 자동 판정 | 숙제 화면에서 일일·주간 진행이 게임과 맞는지 | 틀린 자동 완료(오탐)가 없음. 있으면 카드와 근거 문구 메모 | |
| — | 콘텐츠 추천 | 스탯 → 콘텐츠 추천이 WPF판 대시보드와 같은지 | 입장·추천 난이도가 같음 | |

## 2. 폰·태블릿 연결 (기기 4종)

PC 화면 상단의 📱 버튼 → **LAN 모드 켜기** → QR을 폰 카메라로 찍습니다.

| # | 항목 | 아이폰 12 (Safari) | 아이패드 에어 4 (Safari) | 탭 S10 울트라 (삼성 인터넷·Chrome) | 트라이폴드 (삼성 인터넷·Chrome) |
|---|---|---|---|---|---|
| 페어링 | QR을 찍으면 입력 없이 "연결됐습니다" | | | | |
| M4 | 연결 후 주소창이 `mobimate.local:17800`인지(IP면 이름 해석 실패) | | | | |
| 홈 화면 | "홈 화면에 추가" 후 아이콘(청록 M)으로 열림 | | | | |
| 화면 | 개요 카드가 겹치거나 잘리지 않음 | | | | |
| 조작 | 채팅 전송, 숙제 체크, 긴급 정지(빨간 버튼) | | | | |

| 절전 | 화면을 끄고 5분 뒤 켜면 몇 초 안에 다시 연결되고 최신 값으로 바뀜 | | | | |
