# MobiMate Web 실기 점검 체크리스트

> 대상: 承雲 PC(게임 설치) + 보유 기기 4종(아이폰 12 · 아이패드 에어 4 · 갤럭시 탭 S10 울트라 · 갤럭시 트라이폴드)
> 근거: 요구사양서 TST-05b · TST-07, 상세설계 §9 M1~M10
> 결과는 각 항목의 "결과" 칸에 적어 주시면 됩니다(○ / × / 메모). × 항목은 설명과 함께 알려 주시면 고칩니다.

## 0. 준비 (약 5분)

1. `web\dist\MobiMateWeb.exe`를 실행합니다(.NET 8 데스크톱 런타임 필요). 브라우저가 열리고 개요 화면이 보이면 됩니다.
   - 이미 실행 중이면 트레이의 **MobiMate → 브라우저 열기**를 누릅니다.
2. 게임을 켜고 설정에서 **"MM AI 에이전트"**를 켭니다. 상단 바 왼쪽 점이 초록이면 연결된 것입니다.
3. 폰·태블릿과 PC가 **같은 와이파이**인지 확인합니다. Windows 네트워크 프로필이 **개인**이어야 합니다.

## 4. v1.5 새 기능 확인 (1.0)

| # | 항목 | 방법 | 기대 결과 | 결과 |
|---|---|---|---|---|
| N1 | 접속 | 트레이의 **브라우저 열기**(또는 exe 실행) | 코드 없이 바로 열리고 첫 화면이 "내 캐릭터" 전체 현황 | |
| N2 | 반쪽 화면 배치 | 모니터를 좌우 반으로 나눈 창(FHD 960 폭)에서 각 화면 | 카드가 겹치거나 잘리지 않고 상단(캐릭터·전투력·마도저항·날씨 그림)이 한눈에 들어옴 | |
| N3 | 채팅창 켠 전체 화면 | 전체 화면에서 채팅 도크를 켬 | 가운데에 큰 빈 공간이 없음 | |
| N4 | 전투력 재확인 | 게임 로딩 직후 새로고침을 여러 번 | 전투력이 3,000쯤 낮게 보이지 않음(보이면 몇 초 뒤 제값으로 돌아옴) | |
| N5 | 점수 색 | 전투력 103,000↑ · 마도저항 4,400↑ · 매력 구간별 | 게임 안의 색과 같은지 (연보라 / 붉은색 / 파랑·보라·핑크·골드) | |
| N6 | 즐겨찾기 | 가방·생활(채집)에서 별을 눌러 보기 | 즐겨찾기가 맨 위로 오고, 가방은 즐겨찾기만 이번 접속 증가량이 보임 | |
| N7 | 가공 종류 | 생활 → 가공 대기열 | 금속·목재·가죽·옷감·약품·식재료로 묶임. 어긋난 이름은 알려 주세요 | |
| N8 | 레이더 | 주변에 친구·길드원이 있을 때 | 파티원 > 친구 > 길드원 > 그 외, 색·굵은 글씨 구분, "클래스 - 레벨 - 전투력 - 칭호" | |
| N9 | 색상 패턴 | 설정 → 다크 모드 색상 | 바다·먹물·보라·숲이 바뀌고 글자가 잘 보임 | |
| N10 | 별칭 | 이름 옆 연필 | 그 자리에서 별칭을 고치고, 지우면 원래 이름으로 돌아옴 | |
| N11 | 빠른 실행 | PC에서 Ctrl+K | 화면 이동·채집 재료·페르소나 검색해서 바로 실행 | |
| N12 | 알림·진동 | 가공 완료·가방 100%·주간 리셋 1시간 전 | 화면이 켜진 동안 알림이 뜨고 삼성 기기는 진동 (아이폰은 알림만) | |
| N13 | AI 도우미 | 채팅 → AI 도우미(내장 모드) | 한 줄에 버튼 하나, 가로 스크롤 없이 누르면 해당 화면으로 이동 | |

## 4-1. 후속 개선 확인 (1.0 이후)

| # | 항목 | 방법 | 기대 결과 | 결과 |
|---|---|---|---|---|
| P1 | 캐릭터 선택창 | 게임에서 캐릭터 선택 화면으로 나가 있기 | "에린 · 밀레시안 · Lv.0"이 보이지 않고 상단에 "캐릭터 선택 중"(마지막 캐릭터 흐림) | |
| P2 | 에린 날짜 | 상단 날씨 그림 | "0월"이 없고 "N월 D일"로 보임. 날짜(일)도 이상하게 0이 나오는지 | |
| P3 | 계정 묶기 | 전체 화면 | 같은 계정 캐릭터가 한 묶음, 데카·M캐시가 머리글에 보임. 잘못 묶이면 "계정 편집"으로 고치기 | |
| P4 | 충전 재화 예상 | 오래 접속 안 한 캐릭터 | 은동전·마족 공물 예상 개수가 게임에서 직접 본 값과 비슷함(오차가 크면 알려 주세요) | |
| P5 | 카드 색 | 가득/80%↑/동기화 안 됨 | 붉은색 / 노랑 / 진회색과 작은 글씨 설명 | |
| P6 | 멤버십 | 최상단 "멤버십 미등록" 누르기 | 캐시샵 남은 기간 입력 → 남은 시간이 자동으로 줄고 3일 이내면 붉게 | |
| P7 | 레이더 | 친구·파티원·길드원이 있을 때 | 친구 > 파티원 > 길드원 > 그 외, 줄 맨 앞 (친구)(파티원)(길드원) | |
| P8 | 채팅 | 가로 화면 / 세로 화면 / 폰 | 가로는 기본 열림, 세로는 닫힘, 아이콘으로 닫기, 폰은 한 화면 가득 | |
